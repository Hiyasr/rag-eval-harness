# Installing Fluxo

Fluxo is a command line tool for running data sync jobs between databases.

## Requirements

Fluxo requires Python 3.9 or newer and works on Linux, macOS and Windows. It needs at least 512 MB of free memory for small jobs.

## Install with pip

Run `pip install fluxo-cli` to install the latest release. To upgrade later, run `pip install --upgrade fluxo-cli`.

## Verify the installation

Run `fluxo --version` to confirm the installation. The command prints the installed version number and exits with code 0.
